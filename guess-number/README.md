# Угадай число (наоборот)

Программа угадывает загаданное вами число в диапазоне `[n, m]`.

## Запуск

Из корня репозитория в REPL:

```clojure
(load-file "guess-number/game.clj")
(start 1 100)
(guess-my-number)
;; (smaller) — загаданное меньше попытки
;; (bigger)  — загаданное больше попытки
```

## Функции

| Функция | Описание |
|---------|----------|
| `start` | Начать игру с диапазоном `[n, m]` |
| `guess-my-number` | Следующая попытка |
| `smaller` | Загаданное число меньше |
| `bigger` | Загаданное число больше |
