# Виртуальный плоттер

Функциональная переписка `plotter.ts` на Clojure.

## Запуск

Из корня репозитория в REPL:

```clojure
(load-file "plotter/plotter.clj")
(run-demo)
```

## Файлы

| Файл | Описание |
|------|----------|
| `plotter.clj` | Плоттер на Clojure (функциональный стиль) |
| `plotter.ts` | Исходник на TypeScript (процедурный стиль) |

## Команды

`move`, `turn`, `carriage-up`, `carriage-down`, `set-color`, `set-position`, `draw-triangle`, `draw-square`
